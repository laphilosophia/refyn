Thank you for your interest in contributing to Refyn! 🎉

We welcome contributions of all kinds — bug reports, feature requests, documentation fixes, and code changes.

Please follow these guidelines to make the review process smooth and fast:

1. Create an issue first
   - If your change is a bug or feature request, open an issue describing the problem or proposal. Use the provided issue templates.

2. Fork & branch
   - Fork the repository and create a branch named `fix/your-brief-description` or `feat/your-brief-description`.

3. Code style & tests
   - Run `pnpm install` at the repo root and run checks: `pnpm test`, `pnpm lint`.
   - Add tests for new behavior where applicable.
   - Keep changes focused and small; one logical change per PR.

4. Commit messages
   - Use Conventional Commits style (e.g., `feat: add streaming API`, `fix: handle null values`).

5. Pull request
   - Link to the related issue, explain the motivation, and include a short description of the change.
   - Use the PR template and make sure checks pass in CI.

6. Review process
   - Be responsive to review feedback and update your PR as requested. Maintain a respectful and constructive tone.

Code of Conduct

- By participating, you agree to follow the project's Code of Conduct: see `CODE_OF_CONDUCT.md`.

Thank you — your contribution matters! 🙌
